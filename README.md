# Gatekeeper experiments

Experiments on a gatekeeper that decides whether an LLM prompt and answer record is safe to keep permanently before it is anchored on a blockchain.

| Path | Content |
|---|---|
| `build_eval_v1.ipynb` | Builds the 3,500-record evaluation set |
| `Gatekeeper_v1.ipynb` | API experiments and results |
| `Gatekeeper_v1_local.ipynb` | Local detectors (Presidio, GLiNER, detect-secrets, Granite Guardian) |
| `scripts/` | Shared code. Self-tests: `python scripts/gate.py`, `python scripts/build_eval.py` |
| `data/frames_v1.jsonl` | Generated message frames with empty slots |
| `out/eval_v1_runs/scores_v1.json` | Result tables |
| `out/eval_v1_logs/` | Notebook builders and run script |

## Not in this repo

- Source datasets and the built set. They hold real conversation text, and some are gated. Get them from the sources: WildChat-1M (ODC-BY), Aegis 2.0 (CC BY 4.0), PUPA (MIT), WildJailbreak (gated).
- Raw model answers.
- API keys. Put `OPENROUTER_API_KEY` and `TYPESAFE_API_KEY` in `.env`.
- `scripts/baseline_prompt.txt` (prompt A, from an unpublished paper). Experiments that use prompt A need it.

All credentials and personal values in the set are fake and generated by code.
