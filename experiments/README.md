# Gatekeeper experiments

Experiments on a gatekeeper that decides whether an LLM prompt and answer record is safe to keep permanently before it is anchored on a blockchain. A record is risky if it holds personal information (PII), a credential, or harmful content.

Full write-up of every step, decision and result: [docs/code_walkthrough.md](docs/code_walkthrough.md). Korean translation, for reference: [docs/code_walkthrough.ko.md](docs/code_walkthrough.ko.md).

## Results (test split, 2,436 records, 1,044 risky)

| | Paper gate | Gate v1 | Gate v2 |
|---|---|---|---|
| Recall | 0.352 | 0.955 | 0.982 |
| False-positive rate | 0.078 | 0.127 | 0.300 |
| Cost per record, r = 4 | 1.156 | 0.150 | 0.203 |
| Cost per record, r = 25 | 6.992 | 0.555 | 0.367 |
| Risky records sent to an outside API | 100% | 100% | 11.2% |

- Paper gate: the baseline prompt (user prompt only), 3-of-5 LLM vote. It was built for another task (harmful prompts).
- Gate v1: regex, then `gpt-6-luna` with one prompt for PII and one for credentials, and Jev for harmful content.
- Gate v2: regex and local detectors on the device first; records they pass get v1's questions.
- Cost = (false positives + r × misses) / records. The notebook also shows cost for lower risky shares and r from 1 to 1,000.

## Files

| Path | Content |
|---|---|
| `build_eval_v1.ipynb` | Builds the 3,500-record evaluation set (7 groups of 500) |

| `scripts/secretscan.py` | Regex and entropy scanner for secrets and PII |

| `out/eval_v1_runs/scores_v1.json` | All result tables |
| `out/eval_v1_logs/run_all.sh` | Full API runs, one process per model |

Self-tests (no API call): `python scripts/secretscan.py`, `python scripts/gate.py`, `python scripts/build_eval.py`.

## Rerun

1. Get the source datasets into `Dataset/` (see below) and run `scripts/scan_wildchat.py`.
2. `build_eval_v1.ipynb`: writes `data/eval_v1.jsonl`. No API call while `data/frames_v1.jsonl` is present.
3. `out/eval_v1_logs/run_all.sh` or the run cells of `Gatekeeper_v1.ipynb`: API runs. Resumable.
4. `Gatekeeper_v1_local.ipynb`: local detectors (about 3 hours, mostly Granite Guardian).
5. `Gatekeeper_v1.ipynb`: all tables.

## Not in this repo

- Source datasets and the built set. They hold real conversation text, and some are gated. Sources: WildChat-1M (ODC-BY), Aegis 2.0 (CC BY 4.0).
- Raw model answers (`out/eval_v1_runs/*.jsonl`).
- API keys. Put `OPENROUTER_API_KEY` and `TYPESAFE_API_KEY` in `.env`.
- `scripts/baseline_prompt.txt` (prompt A, from an unpublished paper). Experiments that use prompt A need it.

All credentials and personal values in the set are fake and generated by code. Documentation examples (such as AWS and Stripe sample keys from their public docs) appear only as label-0 hard negatives.
